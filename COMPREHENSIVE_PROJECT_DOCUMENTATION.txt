# COMPREHENSIVE PROJECT DOCUMENTATION
# PixCraft AI - Intelligent Retail Media Business Operating System

## PROJECT OVERVIEW

**Project Name**: PixCraft AI / Retail Media Hack
**Project Type**: Full-Stack AI-Powered Business Operating System for Retailers
**Architecture**: MERN Stack (MongoDB, Express.js, React + TypeScript, Node.js)
**Primary Purpose**: Comprehensive AI-powered business management platform specifically designed for retail businesses (Kirana stores, small retailers) combining creative content generation, business intelligence, and operational management.

## CORE CONCEPT & VISION

This project represents a paradigm shift from simple AI image generation tools to a complete Business Operating System (BOS) that leverages artificial intelligence to transform how retail businesses operate. The platform serves as a unified digital assistant that handles everything from creative content generation to business analytics, competitor monitoring, customer communication, and strategic planning.

## PROJECT ARCHITECTURE

### TECHNOLOGY STACK

#### Backend Technologies
- **Runtime**: Node.js 18+
- **Framework**: Express.js 4.18.2
- **Database**: MongoDB with Mongoose ODM 8.0.3
- **Authentication**: JSON Web Tokens (JWT) 9.0.2 with bcryptjs 2.4.3
- **File Storage**: Cloudinary 1.41.0
- **Validation**: express-validator 7.0.1
- **HTTP Client**: Axios 1.6.2
- **File Upload**: Multer 1.4.5-lts.1
- **Logging**: Morgan 1.10.0
- **CORS**: cors 2.8.5
- **Environment**: dotenv 16.3.1

#### Frontend Technologies
- **Framework**: React 18.2.0 with TypeScript 4.9.5
- **Routing**: React Router DOM 6.20.1
- **HTTP Client**: Axios 1.6.2
- **Animations**: Framer Motion 10.16.16
- **Notifications**: React Hot Toast 2.4.1
- **Build Tool**: Create React App 5.0.1
- **Styling**: Custom CSS with CSS Variables + TailwindCSS concepts

#### AI & External Services
- **Primary AI**: Google Gemini API (Generative AI) 0.24.1
- **Image Generation**: Pollinations AI API
- **Image Editing**: Canva API (planned) + Gemini Vision
- **Cloud Storage**: Cloudinary
- **Background Removal**: Remove.bg API (planned)

## FEATURE BREAKDOWN & FUNCTIONALITY

### 1. AUTHENTICATION & USER MANAGEMENT

#### User Authentication System
- **Registration**: Complete user onboarding with email validation
- **Login/Logout**: JWT-based authentication with 7-day token expiry
- **Password Security**: bcrypt hashing with salt rounds
- **Role-Based Access**: User and Admin roles with different permissions
- **Profile Management**: Avatar, name, email, password change
- **Protected Routes**: Frontend and backend route protection

#### Admin Panel
- **User Management**: View, enable/disable, delete users
- **System Statistics**: Total users, active users, AI generations/edits
- **AI Usage Logs**: Track all AI operations and usage patterns
- **Role Management**: Promote/demote user roles

### 2. AI-POWERED CREATIVE GENERATION

#### Image Generation Engine
- **Multi-Provider AI**: Primary Gemini API with Pollinations AI
- **Style Options**: Realistic, Artistic, Cartoon, Abstract, Photographic
- **Size Variants**: 512x512, 1024x1024, 1024x1792, 1792x1024
- **Batch Generation**: 1-4 images per request
- **Prompt Enhancement**: AI-powered prompt optimization
- **Text Preservation**: Maintains specific text content in generated images
- **Cultural Sensitivity**: Respects cultural elements and languages

#### Advanced Image Editing
- **AI-Powered Editing**: Canva API integration with Gemini Vision fallback
- **Edit Types**: Resize, Crop, Filter application, Text overlay
- **Filter Options**: Grayscale, Sepia, Blur, Sharpen, Vintage
- **Background Removal**: Remove.bg integration (planned)
- **Real-time Preview**: Live preview of edits before applying

#### AI Orchestrator System
- **Natural Language Processing**: Converts user requests to API workflows
- **Multi-Step Operations**: Chains multiple AI operations automatically
- **Workflow Analysis**: Intelligent routing to appropriate AI services
- **Fallback Mechanisms**: Robust error handling and service alternatives
