# 🎤 Quick Reference: Voice Commands for New Products

## 🇬🇧 English Commands

### Create New Product (Explicit)
```
"new product butter 10"
"create chocolate 20"
"add new sugar 15"
"start selling tea 30"
```

### Create New Product (Auto)
```
"add 25 coffee"  (if coffee doesn't exist)
"put 30 biscuit"  (if biscuit doesn't exist)
```

### Update Existing Product
```
"add 5 rice"  (if rice exists)
"sold 2 soap"  (if soap exists)
```

---

## 🇮🇳 Tamil Commands (தமிழ்)

### Create New Product (Explicit)
```
"புதிய பொருள் வெண்ணெய் பத்து"
"புதிய சாக்லேட் இருபது"
"புதிதாக டீ முப்பது சேர்"
```

### Create New Product (Auto)
```
"பதினைந்து காபி சேர்"  (if காபி doesn't exist)
"இருபது பிஸ்கட் சேர்"  (if பிஸ்கட் doesn't exist)
```

### Update Existing Product
```
"ஐந்து அரிசி சேர்"  (if அரிசி exists)
"இரண்டு சோப் விற்பனை"  (if சோப் exists)
```

## 💡 Pro Tips

1. **Use Keywords**: Say "new product" or "புதிய பொருள்" for clarity
2. **Auto-Create**: Just say the product name - if it doesn't exist, it will be created
3. **Translation**: Tamil names are automatically translated to English
4. **Default Unit**: New products get "piece" as default unit (you can edit later)
5. **Undo**: You can undo new product creation within 5 minutes
